# คำถามเชิงวิเคราะห์: PM2.5 Explorer

ช่วงข้อมูลสำหรับสำรวจ: 2563–2566 · ช่วงข้อมูลสำหรับทดสอบ: 2567–2568

## ส่วนที่ 1: คำถามก่อนเห็นข้อมูล (prior)

### Q1. <คำถาม>
- **ที่มา:** ความรู้ในโดเมน / รายงาน-งานวิจัย / ผู้มีส่วนได้ส่วนเสีย / การสังเกต
- **เหตุผล:** <ทำไมคิดว่าน่าจะเป็นแบบนั้น>
- **ตัวชี้วัด:** <จะคำนวณอะไร จากตัวแปรไหน ใช้เกณฑ์อะไร>
- **คำตอบที่คาด:** <...>
- **ถ้าคำตอบไม่เป็นอย่างที่คาด แปลว่า:** <...>
- **ข้อมูลที่ต้องใช้:** <ตัวแปร ช่วงเวลา พื้นที่>
- **ใครใช้คำตอบนี้:** <...>

ตรวจคำถามของตนเองด้วยเกณฑ์ 4 ข้อจากเอกสารประกอบการสอน หัวข้อที่ 2 ถ้าข้อใดไม่ผ่าน ให้เขียนใหม่

เกณฑ์ ตัวอย่างที่ไม่ผ่าน ปรับเป็น
เฉพาะเจาะจง “ฝุ่นในอีสานเป็นอย่างไร” “PM2.5 รายวันในอุบลราชธานี ม.ค.–เม.ย. เทียบ มิ.ย.–ก.ย.”
วัดได้ “คนอุบลฯ เดือดร้อนจากฝุ่นแค่ไหน” “จำนวนวันที่เกิน 37.5 µg/m³ ต่อปี”
คำตอบเป็นไปได้หลายแบบ “วันที่ฝุ่นสูงมีค่าฝุ่นสูงไหม” “วันที่ PM2.5 สูงมี PM10 สูงตามหรือไม่”
นำไปใช้ได้ “ค่าฝุ่นเฉลี่ยทั้งประเทศ 5 ปีเท่าไร” “ชั่วโมงใดของวันที่ไม่ควรจัดกิจกรรมกลางแจ้ง”

ขั้นที่ 4: first look ข้อมูลปัจจุบันจาก Air4Thai

สร้าง notebooks/02_first_look.ipynb เลือก kernel dstoolbox แล้วเพิ่ม Markdown cell แรกว่า “First look: ดูโครงสร้าง ช่วงเวลา หน่วย และค่าหาย ไม่วิเคราะห์”

cell 1: ดึงข้อมูลปัจจุบัน (สัปดาห์ที่ 3 จะเขียนเป็น script จริงจัง สัปดาห์นี้ดูอย่างเดียว)

import requests
import pandas as pd
import truststore; truststore.inject_into_ssl()     # ดูตารางแก้ปัญหา: SSLError

URL = "http://air4thai.pcd.go.th/services/getNewAQI_JSON.php"
r = requests.get(URL, timeout=30)
r.status_code, r.headers.get("Content-Type")

cell 2: ดู key ก่อนเสมอ อย่าเชื่อเอกสารนี้

data = r.json()
print(type(data), list(data.keys()) if isinstance(data, dict) else len(data))
stations = data["stations"]          # ถ้า key ไม่ชื่อนี้ ให้แก้ตามที่เห็นจาก cell ก่อนหน้า
print(len(stations))
stations[0]                          # ดูโครงสร้างของสถานีแรกทั้งก้อน

cell 3: แปลงเป็นตารางแบน

df_now = pd.json_normalize(stations)
print(df_now.shape)
df_now.columns.tolist()              # ชื่อคอลัมน์ที่ซ้อนกันจะต่อด้วยจุด เช่น "<key>.<subkey>"

เขียน Markdown cell ตอบคำถามต่อไปนี้จากสิ่งที่เห็นจริง

  1. หนึ่งแถวของ df_now คืออะไร (หนึ่งสถานี ณ เวลาล่าสุด?)
  2. คอลัมน์ใดเก็บรหัสสถานี ชื่อ พิกัด วันที่ และเวลา
  3. ค่า PM2.5 อยู่คอลัมน์ไหน มีทั้ง ค่าความเข้มข้น และ ค่า AQI หรือไม่ หน่วยคืออะไร
  4. ค่าตัวเลขถูกเก็บเป็นข้อความ (object) หรือตัวเลข มีค่าแปลก เช่น ค่าลบ หรือ "-" แทนค่าหายหรือไม่

cell 4: ตรวจค่าหายและค่าแปลก (แทน <pm25_col> ด้วยชื่อคอลัมน์จริง)

pm = pd.to_numeric(df_now["<pm25_col>"], errors="coerce")
print("แปลงเป็นตัวเลขไม่ได้:", pm.isna().sum())
print("ค่าติดลบ:", (pm < 0).sum())
pm.describe()

ข้อมูลปัจจุบันมีแค่เวลาเดียวต่อสถานี จึงดูช่วงเวลาและความถี่ไม่ได้ ใช้ขั้นที่ 5 แทน

ขั้นที่ 5: first look ไฟล์ตัวอย่างย้อนหลัง (เฉพาะช่วงสำรวจ)

ถ้าดึงข้อมูลในขั้นที่ 4 ไม่ได้ ให้ข้ามมาขั้นนี้ได้เลย

hourly = pd.read_csv("../data/sample/pm25_hourly_sample.csv", parse_dates=["ts"])
st = pd.read_csv("../data/sample/stations_sample.csv")

# ใช้เฉพาะช่วงสำรวจ 2563–2566 (ค.ศ. 2020–2023) ห้ามดูช่วงทดสอบ
explore = hourly[hourly["ts"] < "2024-01-01"]

print(explore.shape, explore["station_id"].nunique(), "สถานี")
print(explore["ts"].min(), "→", explore["ts"].max())
print(explore["ts"].diff().value_counts().head(3))   # ความถี่ของข้อมูล (ควรเป็น 1 ชั่วโมง)
explore.isna().mean().round(3)
# สถานีที่ค่า PM2.5 หายมากที่สุด 10 อันดับ (ดูว่าค่าหายอยู่ตรงไหน ยังไม่ตัดสินว่าทำไม)
(explore.groupby("station_id")["pm25"]
        .apply(lambda s: s.isna().mean())
        .sort_values(ascending=False)
        .head(10))

เขียน Markdown cell สรุปสิ่งที่เห็น 3–5 ข้อ ใช้ถ้อยคำแบบ “พบว่า… ควรตรวจสอบต่อ” ไม่ใช่ “พิสูจน์ว่า…”
