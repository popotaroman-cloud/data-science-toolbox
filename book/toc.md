# ชุดเครื่องมือสำหรับวิทยาการข้อมูล
## การสำรวจข้อมูลเชิงลึกด้วย Python และ SQL ตั้งแต่แหล่งข้อมูลถึงแดชบอร์ด

หนังสือประกอบการสอนรายวิชา 1145100 Data Science Toolbox · วาโย ปุยะติ · มหาวิทยาลัยอุบลราชธานี

> **แนวคิดของเล่ม:** เอกสารประกอบการสอนรายสัปดาห์ตอบว่า *ทำอย่างไร* หนังสือเล่มนี้ตอบเพิ่มว่า *ทำไม* และ *ลึกลงไปเป็นอย่างไร*
> ทุกบทอ่านจบในตัว ใช้ข้อมูล PM2.5 ของประเทศไทยเป็นกรณีศึกษาต่อเนื่องทั้งเล่ม และมีเนื้อหาเกินกว่าที่สอนในชั้นเรียน (ทำเครื่องหมาย ★ = เนื้อหาเชิงลึก/เสริม ไม่ได้สอนในชั้นเรียนโดยตรง)

**โครงสร้างมาตรฐานของทุกบท:** วัตถุประสงค์ → เนื้อหา → กรณีศึกษา PM2.5 → ข้อผิดพลาดที่พบบ่อย → สรุป → แบบฝึกหัด (พื้นฐาน / ประยุกต์ / ท้าทาย) → อ่านเพิ่มเติม

## บทที่ 0 ภาพรวมของหนังสือ: เรื่องนี้เกี่ยวกับอะไร และนำไปใช้อย่างไร

0.1 หนังสือเล่มนี้เกี่ยวกับอะไร: การเปลี่ยนข้อมูลดิบให้เป็นความเข้าใจที่เชื่อถือได้
0.2 ทำไมการสำรวจข้อมูลจึงสำคัญ: ตัวอย่างการตัดสินใจที่ผิดเพราะไม่เข้าใจข้อมูล
0.3 ศาสตร์ที่หลอมรวมอยู่ในเล่ม
  - สถิติศาสตร์: การแจกแจง การอนุมาน ความไม่แน่นอน
  - วิทยาการคอมพิวเตอร์และวิศวกรรมซอฟต์แวร์: การเขียนโปรแกรม version control การทดสอบ การทำซ้ำได้
  - ระบบฐานข้อมูล: แบบจำลองเชิงสัมพันธ์ SQL การจัดเก็บแบบ columnar
  - คณิตศาสตร์: พีชคณิตเชิงเส้นและความน่าจะเป็นที่อยู่เบื้องหลัง PCA clustering และการทดสอบ
  - จิตวิทยาการรับรู้และการออกแบบ: การมองเห็น สี และการเล่าเรื่องด้วยภาพ
  - ภูมิสารสนเทศ: ระบบพิกัด แผนที่ ข้อมูลเชิงพื้นที่
  - ความรู้เชิงโดเมน: วิทยาศาสตร์สิ่งแวดล้อมและคุณภาพอากาศ (PM2.5)
  - กฎหมายและจริยธรรม: PDPA ความเป็นส่วนตัว ลิขสิทธิ์ การใช้ AI อย่างรับผิดชอบ
0.4 แผนที่ชุดเครื่องมือ: เครื่องมือแต่ละตัวอยู่ตรงไหนในวงจรข้อมูล และเลือกใช้เมื่อใด
0.5 เส้นทางของเล่ม: สรุปทั้ง 7 ส่วนและความเชื่อมโยงระหว่างบท
0.6 กรณีศึกษาหลัก: ระบบสำรวจคุณภาพอากาศ PM2.5 ของประเทศไทย
0.7 การนำไปใช้ประโยชน์
  - ในการเรียน: โครงงาน สหกิจศึกษา และการเรียนวิชาขั้นสูง (machine learning, big data)
  - ในอาชีพ: data analyst, data engineer, data scientist, analytics engineer และงานที่ต้องใช้ข้อมูลในทุกสาขา
  - ในงานวิจัย: การสำรวจข้อมูลก่อนตั้งสมมติฐานและการรายงานที่ตรวจสอบได้
  - ในภาครัฐและชุมชน: ข้อมูลเปิด การติดตามปัญหาสิ่งแวดล้อม การสื่อสารความเสี่ยงต่อสาธารณะ
  - ในโดเมนอื่น: สาธารณสุข เกษตร พลังงาน การขนส่ง ธุรกิจ (สถาปัตยกรรมเดียวกัน เปลี่ยนแหล่งข้อมูล)
0.8 ความรู้พื้นฐานที่ควรมีก่อนอ่าน และสิ่งที่ไม่ต้องมี
0.9 วิธีอ่านหนังสือเล่มนี้: เส้นทางการอ่านสำหรับผู้เรียน ผู้สอน และผู้อ่านที่มีพื้นฐานแล้ว

### อภิธานศัพท์ (Glossary)
ศัพท์เทคนิคทั้งเล่มประมาณ 250–300 คำ เรียงตามอักษรภาษาอังกฤษ แต่ละคำประกอบด้วย
- คำภาษาอังกฤษ · คำแปล/ศัพท์บัญญัติภาษาไทย (ถ้ามี)
- คำนิยามสั้น 1–3 บรรทัด
- บทที่อธิบายคำนั้นโดยละเอียด และคำที่เกี่ยวข้อง (ดูเพิ่ม)

ตัวอย่างรายการ: *Anti join*, *Autocorrelation*, *Bootstrap*, *Choropleth*, *Columnar storage*, *Commit*, *CRS*, *Data contract*, *Differential privacy*, *Effect size*, *HARKing*, *Idempotent*, *Imputation*, *MCAR/MAR/MNAR*, *Parquet*, *PCA*, *Pull request*, *Robust statistics*, *Sentinel value*, *STL decomposition*, *Tidy data*, *Window function*

ดัชนีคำค้นสองภาษา ชี้ไปยังหัวข้อ (เช่น 7.5) ที่คำนั้นปรากฏ
- **ดัชนีหัวเรื่อง:** แนวคิด เทคนิค และศัพท์ ทั้งภาษาไทยและภาษาอังกฤษ
- **ดัชนีเครื่องมือและฟังก์ชัน:** ไลบรารี คำสั่ง และฟังก์ชันที่ยกตัวอย่าง เช่น `duckdb.connect`, `pd.melt`, `st.cache_data`
- **ดัชนีชุดข้อมูลและกรณีศึกษา:** ตารางและตัวอย่าง PM2.5 ที่ใช้ในแต่ละบท
