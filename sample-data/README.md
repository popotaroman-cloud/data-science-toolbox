# ไฟล์ตัวอย่างของรายวิชา 1145100 Data Science Toolbox

ข้อมูลจริงจาก Air4Thai (กรมควบคุมมลพิษ) ที่ผู้สอนดึงและจัดรูปแบบไว้ล่วงหน้า

| ไฟล์ | เนื้อหา | ใช้ในสัปดาห์ |
|---|---|---|
| `air4thai_sample.json` | response ของ API ค่าปัจจุบัน (178 สถานี) ณ วันที่สร้างไฟล์ | 2–3 |
| `stations_sample.csv` | ตาราง `stations` (178 สถานี มี `province` และ `region`) | 3–5, 13 |
| `pm25_hourly_sample.csv` | ตาราง `measurements` รายชั่วโมง 333,216 แถว | 4–7 |
| `pm25_sample.duckdb` | ฐานข้อมูลที่ผ่านสัปดาห์ที่ 7 แล้ว มี `stations`, `measurements`, `measurements_clean`, view `daily_pm25_clean` | 9 เป็นต้นไป |

- **ช่วงเวลา:** 1 ก.ย. – 17 พ.ย. 2569 รายชั่วโมง
- **ค่าติดลบ** ใน API แทนข้อมูลหาย ไฟล์นี้เก็บเป็นค่าว่าง (`NULL`) แล้ว
- **ช่องว่างในข้อมูล** เป็นของจริงจากต้นทาง ไม่ได้เติมค่าใน `measurements` (สัปดาห์ที่ 7 ทำการเติมเอง)
- **ข้อจำกัด:** API ย้อนหลังของ Air4Thai เก็บข้อมูลประมาณ 3 เดือน ไฟล์ตัวอย่างนี้จึงไม่ครอบคลุมช่วงก่อนหน้า
- **วิธีดึงใหม่:** ดูสคริปต์ `scripts/build_sample_data.py` ใน repo รายวิชา
