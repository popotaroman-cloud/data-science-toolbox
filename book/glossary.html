อภิธานศัพท์

Academic integrity (ความซื่อตรงทางวิชาการ)
การทำงานวิชาการอย่างซื่อตรง ไม่สร้างข้อมูลเท็จ ไม่บิดเบือนข้อมูล ไม่ลอกเลียนผลงาน ในงานข้อมูลรวมถึงการติดป้ายข้อมูลสังเคราะห์และการบันทึกการใช้ AI อธิบายใน ความซื่อตรงทางวิชาการ · ดูเพิ่ม Data ethics, Synthetic data
Accessibility (การเข้าถึงได้)
การออกแบบให้ผู้อ่านทุกกลุ่ม รวมถึงผู้พิการทางการเห็นและผู้มีภาวะตาบอดสี เข้าถึงเนื้อหาได้ สำหรับกราฟได้แก่ alt text ที่บอกข้อค้นพบ ตารางข้อมูลประกอบ และการไม่พึ่งสีอย่างเดียว อธิบายใน การเข้าถึงได้ (accessibility) ของกราฟ · ดูเพิ่ม Visualization
Aesthetic mapping (การจับคู่ตัวแปรกับคุณลักษณะภาพ)
การกำหนดว่าตัวแปรใดในข้อมูลแสดงด้วยคุณลักษณะทางภาพใด เช่น ตำแหน่ง x สี หรือขนาด ต้องใช้ข้อมูลในรูป tidy อธิบายใน grammar of graphics ของ Wilkinson · ดูเพิ่ม Grammar of graphics, Encoding (visual), Tidy data
Aggregation (การรวมกลุ่ม)
การยุบหลายแถวให้เหลือหนึ่งแถวต่อกลุ่ม พร้อมค่าสรุป เช่น AVG, COUNT, MAX ด้วย GROUP BY ฟังก์ชันรวมส่วนใหญ่ข้ามค่า NULL ยกเว้น COUNT(*) อธิบายใน aggregation, GROUP BY ALL และ GROUPING SETS/ROLLUP/CUBE · ดูเพิ่ม Window function
Analytical question (คำถามเชิงวิเคราะห์)
คำถามที่ตอบได้ด้วยข้อมูล มีคุณลักษณะสี่ข้อ คือ เฉพาะเจาะจง วัดได้ มีคำตอบได้มากกว่าหนึ่งแบบ และนำไปใช้ได้ พร้อมระบุเกณฑ์ที่ใช้อย่างชัดเจน อธิบายใน คุณลักษณะของคำถามเชิงวิเคราะห์ที่ดี
Annotation (คำอธิบายประกอบ)
ข้อความ ลูกศร หรือเส้นอ้างอิงที่วางบนกราฟเพื่อชี้ประเด็นและให้บริบท เช่น เส้นมาตรฐาน 37.5 µg/m³ และป้ายบอกค่าสูงสุด อธิบายใน การใส่คำอธิบายประกอบและเส้นอ้างอิง (มาตรฐาน 37.5 µg/m³) · ดูเพิ่ม Visualization
Anonymization (การทำให้เป็นข้อมูลนิรนาม)
การแปลงข้อมูลจนไม่สามารถระบุตัวบุคคลได้อีกด้วยวิธีที่มีเหตุผลตามสมควร ข้อมูลที่เป็นนิรนามแท้จริง ไม่ใช่ข้อมูลส่วนบุคคล แต่ทำได้ยากกว่าที่คิดเพราะ quasi-identifier อธิบายใน anonymization กับ pseudonymization · ดูเพิ่ม Pseudonymization, Re-identification
API (API)
Application Programming Interface ช่องทางที่ระบบหนึ่งเปิดให้โปรแกรมอื่นเรียกใช้ API บนเว็บมักรับ request ผ่าน HTTP และส่งข้อมูลกลับเป็น JSON อธิบายใน REST API: authentication, pagination, rate limit · ดูเพิ่ม Endpoint, Rate limit
Architecture decision record (ADR) (บันทึกการตัดสินใจออกแบบ)
เอกสารสั้นที่บันทึกบริบท สิ่งที่ตัดสินใจ ทางเลือกที่พิจารณา และผลที่ตามมาของการตัดสินใจออกแบบแต่ละข้อ ช่วยให้ผู้อื่นเข้าใจว่าทำไมระบบจึงเป็นแบบนี้ อธิบายใน สถาปัตยกรรมและการตัดสินใจออกแบบ · ดูเพิ่ม Reproducibility
As-of join (as-of join)
การจับคู่แต่ละแถวกับแถวของอีกตารางที่มีเวลาใกล้ที่สุดตามทิศที่กำหนด ควรกำหนดระยะห่างสูงสุดที่ยอมรับได้ (tolerance) อธิบายใน การจัดแนวข้อมูลเซนเซอร์ที่เวลาไม่สม่ำเสมอ · ดูเพิ่ม Join
Autocorrelation (สหสัมพันธ์ในตัว)
สหสัมพันธ์ระหว่างอนุกรมกับตัวเองที่เลื่อนไป k ช่วงเวลา (lag) แสดงด้วย ACF ทำให้ขนาดตัวอย่างที่มีประสิทธิผลต่ำกว่าจำนวนค่าจริง อธิบายใน autocorrelation: ACF และ PACF · ดูเพิ่ม Stationarity
Bias (data) (อคติ)
ความคลาดเคลื่อนเชิงระบบที่ทำให้ผลการวิเคราะห์เอนไปทางใดทางหนึ่ง เกิดได้จากการเลือกตัวอย่าง การวัด ข้อมูลสูญหาย การรวมข้อมูล การตีความ และการรายงาน อธิบายใน อคติในข้อมูลและในการตีความ · ดูเพิ่ม Data ethics, MCAR / MAR / MNAR
Bootstrap (bootstrap)
วิธี resampling ที่สุ่มข้อมูลจากตัวอย่างเดิมแบบใส่คืนซ้ำหลายพันครั้ง เพื่อประมาณการแจกแจงและช่วงความเชื่อมั่นของสถิติใดก็ได้ อธิบายใน resampling: bootstrap และ permutation test · ดูเพิ่ม Permutation test, Confidence interval
Branch (branch)
ป้ายชื่อที่ชี้ไปยัง commit หนึ่งตัวและเลื่อนตามเมื่อมี commit ใหม่ ใช้แยกสายการพัฒนา เพื่อลองของใหม่โดยไม่กระทบ main อธิบายใน แบบจำลองข้อมูลของ Git: blob, tree, commit และ DAG · ดูเพิ่ม Merge / rebase
Caching (caching)
การเก็บผลของการคำนวณหรือทรัพยากรไว้ใช้ซ้ำ Streamlit มี cache_data สำหรับข้อมูล (คืนสำเนา) และ cache_resource สำหรับทรัพยากรที่ใช้ร่วมกัน เช่น การเชื่อมต่อฐานข้อมูล อธิบายใน caching: cache_data กับ cache_resource และการเชื่อมต่อแบบ read-only · ดูเพิ่ม Rerun (Streamlit)
Callback (callback)
ฟังก์ชันที่ Streamlit เรียกก่อน rerun เมื่อ widget เปลี่ยนค่า กำหนดด้วย on_change หรือ on_click เป็นที่เดียวที่แก้ค่าของ widget ใน session state ได้หลังสร้าง widget อธิบายใน แบบจำลองการทำงานของ Streamlit: rerun, session state, callback · ดูเพิ่ม Session state
Change point (change point)
จุดในเวลาที่คุณสมบัติทางสถิติของอนุกรมเปลี่ยนอย่างฉับพลัน อาจเกิดจากปรากฏการณ์จริงหรือจากการเปลี่ยนระบบการวัด อธิบายใน change point detection · ดูเพิ่ม Time series
Choropleth map (แผนที่ choropleth)
แผนที่ที่ระบายสีแต่ละพื้นที่ตามค่าของตัวแปร ต้องแยกพื้นที่ไม่มีข้อมูล แสดงจำนวนข้อมูลต่อพื้นที่ และระวังพื้นที่ใหญ่ครอบงำสายตาและ MAUP อธิบายใน แผนที่ choropleth และปัญหา MAUP · ดูเพิ่ม MAUP
Cluster bootstrap (cluster bootstrap)
bootstrap ที่สุ่มทั้งกลุ่ม เช่น ทั้งสถานี แทนการสุ่มทีละแถว ใช้เมื่อข้อมูลภายในกลุ่มสัมพันธ์กัน ให้ช่วงความเชื่อมั่นที่ซื่อตรงกว่าการถือว่าทุกแถวเป็นอิสระ อธิบายใน การสำรวจและข้อค้นพบ · ดูเพิ่ม Bootstrap, Autocorrelation
Clustering (การจัดกลุ่ม)
การแบ่งหน่วยข้อมูลเป็นกลุ่มที่คล้ายกันภายในและต่างกันระหว่างกลุ่ม โดยไม่มีป้ายคำตอบ เช่น k-means, hierarchical clustering และ DBSCAN ผลขึ้นกับการตัดสินใจของผู้วิเคราะห์ อธิบายใน clustering: k-means, hierarchical, DBSCAN · ดูเพิ่ม Silhouette
Code review (การ review โค้ด)
การให้ผู้อื่นตรวจการเปลี่ยนแปลงของโค้ดก่อนรวม งานข้อมูลควรตรวจความถูกต้องของผลลัพธ์ และจุดเสี่ยงของข้อมูลก่อนความอ่านง่ายของโค้ด อธิบายใน ศิลปะของการ review โค้ด · ดูเพิ่ม Pull request (PR)
Colormap / palette (ชุดสี)
การจับคู่ค่าหรือกลุ่มของข้อมูลกับสี แบ่งเป็น sequential, diverging และ categorical ชุดสีที่ดีสำหรับค่าต่อเนื่องควรมี perceptual uniformity อธิบายใน วิทยาศาสตร์ของสี: perceptual uniformity, sequential/diverging/categorical, ภาวะตาบอดสี · ดูเพิ่ม Encoding (visual)
Columnar storage (การจัดเก็บแบบ columnar)
การเรียงค่าในตารางทีละคอลัมน์ ทำให้อ่านเฉพาะคอลัมน์ที่ต้องการได้และบีบอัดได้ดี เหมาะกับงาน OLAP ใช้ใน DuckDB, Parquet และ Arrow อธิบายใน row store กับ column store · ดูเพิ่ม OLTP / OLAP, Parquet
Commit (commit)
วัตถุใน Git ที่บันทึกสถานะของทั้งโครงการ ณ เวลาหนึ่ง เก็บ hash ของ tree ระดับบน hash ของ commit แม่ ผู้เขียน เวลา และข้อความ commit ต่อกันเป็น DAG อธิบายใน แบบจำลองข้อมูลของ Git: blob, tree, commit และ DAG · ดูเพิ่ม Branch
Completeness (ความครบถ้วน)
สัดส่วนของข้อมูลที่มีจริงเทียบกับที่ควรมี เช่น จำนวนชั่วโมงที่มีค่า (n_hours) ต่อวัน โครงการนี้ใช้เกณฑ์ไม่น้อยกว่า 18 จาก 24 ชั่วโมง ซึ่งเป็นข้อกำหนดของโครงการ อธิบายใน resampling และความครบถ้วนของข้อมูลเมื่อรวมกลุ่ม
Confidence interval (ช่วงความเชื่อมั่น)
ช่วงที่คำนวณจากตัวอย่าง ซึ่งถ้าทำซ้ำกระบวนการหลายครั้ง สัดส่วนที่กำหนด (เช่น 95%) ของช่วงจะครอบคลุมค่าจริง สะท้อนเฉพาะความไม่แน่นอนจากการสุ่มตัวอย่าง อธิบายใน ประชากร ตัวอย่าง และช่วงความเชื่อมั่น · ดูเพิ่ม Bootstrap, Effect size
Confirmatory analysis (การวิเคราะห์เชิงยืนยัน)
การทดสอบข้อสันนิษฐานที่กำหนดไว้ล่วงหน้าด้วยวิธีที่วางแผนไว้ เพื่อสรุปผลพร้อมระดับความไม่แน่นอน ควรใช้ข้อมูลคนละชุดกับที่ใช้สำรวจเพื่อสร้างข้อสันนิษฐานนั้น อธิบายใน EDA กับ Confirmatory Data Analysis · ดูเพิ่ม Exploratory Data Analysis (EDA)
Coordinate Reference System (CRS) (ระบบพิกัดอ้างอิง)
ข้อกำหนดที่บอกว่าตัวเลขพิกัดหมายถึงตำแหน่งใด ประกอบด้วย datum ชนิดของพิกัด และหน่วย ระบุด้วยรหัส EPSG เช่น 4326 (WGS 84) และ 32647 (UTM 47N) อธิบายใน ระบบพิกัดและเส้นโครงแผนที่สำหรับประเทศไทย (WGS 84, UTM 47N/48N) · ดูเพิ่ม Projection, Datum
Correlation (สหสัมพันธ์)
ตัววัดความสัมพันธ์ระหว่างสองตัวแปร Pearson วัดความสัมพันธ์เชิงเส้น Spearman วัดความสัมพันธ์แบบทางเดียวจากลำดับ สหสัมพันธ์ไม่ใช่เหตุและผล อธิบายใน สหสัมพันธ์และกับดัก: Simpson’s paradox, ecological fallacy · ดูเพิ่ม Simpson’s paradox
CTE (CTE)

Data acquisition (การได้มาซึ่งข้อมูล)

Data dictionary (พจนานุกรมข้อมูล)
เอกสารที่อธิบายทุกตารางและทุกคอลัมน์ รวมถึงหน่วย เขตเวลา ความหมาย และการตัดสินใจที่ส่งผลต่อการตีความ เช่น การแปลงค่าแทน อธิบายใน การจัดทำเอกสารข้อมูล: data dictionary และ Datasheets for Datasets

Data lifecycle (วงจรชีวิตข้อมูล)
ลำดับขั้นที่ข้อมูลผ่านตั้งแต่ตั้งคำถาม ได้มา จัดเก็บ แปลงรูป ตรวจคุณภาพ สำรวจ จนถึงสื่อสารผล เป็นวงจรที่ย้อนกลับได้ เช่น CRISP-DM และ OSEMN อธิบายใน แบบจำลองวงจรชีวิตข้อมูล: CRISP-DM, OSEMN และวงจรของหนังสือเล่มนี้ · ดูเพิ่ม Pipeline
Data profiling (data profiling)
การสรุปลักษณะของข้อมูลทุกคอลัมน์อย่างเป็นระบบ เช่น ชนิด ค่าว่าง การแจกแจง และค่าซ้ำ เพื่อหาปัญหาของข้อมูล ไม่ได้แทนการตีความของผู้วิเคราะห์ อธิบายใน data profiling: ทฤษฎีและเครื่องมือ
Data quality (คุณภาพข้อมูล)

Data science (วิทยาการข้อมูล)

การสื่อสารผลการวิเคราะห์ที่จัดโครงสร้างตามความต้องการของผู้อ่าน ข้อค้นพบก่อน หลักฐานตาม พร้อมบริบทของตัวเลข ข้อจำกัด และความไม่แน่นอน อธิบายใน โครงสร้างการเล่าเรื่อง: ข้อค้นพบก่อน หลักฐานตาม · ดูเพิ่ม Literate programming
Data-ink ratio (อัตราส่วนหมึกข้อมูล)

Database (ฐานข้อมูล)
ระบบที่จัดเก็บข้อมูลอย่างมีโครงสร้าง และให้ค้นหาและแก้ไขได้ด้วยภาษาอย่าง SQL พร้อมบังคับกฎความถูกต้อง เช่น primary key อธิบายใน relational model: relation, key และ integrity · ดูเพิ่ม Primary key, Table / view
DataFrame (DataFrame)
โครงสร้างข้อมูลตารางในหน่วยความจำของ pandas หรือ Polars แต่ละคอลัมน์มีชนิดข้อมูล (dtype) pandas มี index ที่ใช้จัดแนวข้อมูลอัตโนมัติ ส่วน Polars ไม่มี index อธิบายใน pandas เชิงลึก: index, dtype, copy-on-write และ Arrow-backed dtype
Datashader (Datashader)
ไลบรารีที่แสดงข้อมูลจุดจำนวนมหาศาลด้วยการนับจำนวนจุดต่อพิกเซลแล้วแปลงเป็นสี แก้ทั้งปัญหา overplotting และขนาดข้อมูลที่ส่งไปยังเบราว์เซอร์ อธิบายใน visualization ข้อมูลขนาดใหญ่: binning, aggregation และ Datashader · ดูเพิ่ม Overplotting

Domain knowledge (ความรู้เชิงโดเมน)

Drill-down (drill-down)

Facet / small multiples (facet / small multiples)

Garden of forking paths (garden of forking paths)
ปรากฏการณ์ที่ทางเลือกเล็ก ๆ จำนวนมากในการวิเคราะห์ ซึ่งตัดสินใจหลังเห็นข้อมูล ทำให้ผลดูมีนัยสำคัญเกินจริง แม้ทดสอบเพียงครั้งเดียวและไม่มีเจตนาโกง อธิบายใน Garden of forking paths, HARKing และ p-hacking · ดูเพิ่ม HARKing, Multiple comparisons

การแทนตัวระบุโดยตรงด้วยรหัสแฝง โดยเก็บตารางจับคู่หรือกุญแจไว้แยก ลดความเสี่ยง แต่ข้อมูลที่แฝงแล้วยังเป็นข้อมูลส่วนบุคคล อธิบายใน anonymization กับ pseudonymization · ดูเพิ่ม Anonymization

คำขอให้รวม branch หนึ่งเข้าอีก branch หนึ่งบนบริการอย่าง GitHub พร้อมพื้นที่อภิปรายและ review ก่อนรวม อธิบายใน GitHub: remote, pull request, issue และ code review · ดูเพิ่ม Code review
Query (query)
คำสั่งที่ส่งให้ฐานข้อมูลเพื่อขอข้อมูล เช่น SELECT ใน SQL ผู้ใช้บอกว่าต้องการผลลัพธ์อะไร ฐานข้อมูลเป็นผู้เลือกวิธีทำงานที่เร็วที่สุด อธิบายใน ลำดับการประมวลผลเชิงตรรกะของคำสั่ง SELECT
Rate limit (rate limit)
ขีดจำกัดจำนวน request ต่อช่วงเวลาที่ผู้ให้บริการกำหนด เมื่อเกินมักได้ status 429 พร้อม header Retry-After บอกระยะเวลาที่ควรรอ อธิบายใน REST API: authentication, pagination, rate limit
Raw data (ข้อมูลดิบ)
ข้อมูลในรูปที่ได้รับจากแหล่งต้นทางโดยยังไม่ผ่านการแปลง เก็บแยกไว้และไม่เขียนทับ เพื่อให้ประมวลผลใหม่ได้เมื่อพบว่าขั้นแปลงผิดพลาด อธิบายใน การดึงข้อมูลอย่างทนทาน: timeout, retry, backoff, idempotency
Re-identification (การระบุตัวตนซ้ำ)
การเชื่อมข้อมูลที่ลบตัวระบุแล้วเข้ากับข้อมูลภายนอกจนรู้ว่าแถวใดเป็นของใคร มักอาศัย quasi-identifier เช่น อายุ เพศ และที่อยู่ อธิบายใน k-anonymity, l-diversity และการโจมตีเพื่อระบุตัวตนซ้ำ · ดูเพิ่ม Anonymization
Repository (repo) (repository)
โฟลเดอร์โครงการที่ Git ติดตามการเปลี่ยนแปลง ประกอบด้วยไฟล์ที่ทำงานอยู่และฐานข้อมูลประวัติในโฟลเดอร์ .git/ อธิบายใน แบบจำลองข้อมูลของ Git: blob, tree, commit และ DAG
Reproducibility (การทำซ้ำได้)
การได้ผลที่สอดคล้องกันเมื่อใช้ข้อมูลเดียวกัน โค้ดเดียวกัน และเงื่อนไขการวิเคราะห์เดียวกัน ต่างจาก replicability ซึ่งศึกษาคำถามเดิมด้วยข้อมูลชุดใหม่ อธิบายใน วิกฤตการทำซ้ำได้ (reproducibility crisis) และระดับของการทำซ้ำได้
Request / response (request / response)

Rerun (Streamlit) (rerun)
แบบจำลองการทำงานของ Streamlit ที่รัน script ทั้งไฟล์ใหม่ตั้งแต่บรรทัดแรกทุกครั้งที่ผู้ใช้โต้ตอบกับ widget จึงต้องใช้ session state เก็บค่าข้ามรอบ และ cache ป้องกันงานซ้ำ อธิบายใน แบบจำลองการทำงานของ Streamlit: rerun, session state, callback · ดูเพิ่ม Session state, Caching
Resample (resample)
การรวมหรือแตกข้อมูลอนุกรมเวลาเป็นช่วงเวลาใหม่ เช่น รายชั่วโมงเป็นรายวัน resample ของ pandas สร้างแถวของทุกช่วงเวลาแม้ไม่มีข้อมูล ต่างจาก groupby อธิบายใน resampling และความครบถ้วนของข้อมูลเมื่อรวมกลุ่ม · ดูเพิ่ม Completeness
Reshape (การปรับรูป)
การเปลี่ยนรูปของตารางโดยไม่เปลี่ยนข้อมูล เช่น melt จากกว้างเป็นยาว และ pivot จากยาวเป็นกว้าง pivot แจ้ง error เมื่อมีแถวซ้ำ ซึ่งเป็นสัญญาณให้ตรวจข้อมูล อธิบายใน reshaping: melt, pivot และ wide/long
Robust statistics (สถิติแบบทนทาน)
สถิติที่ไม่เปลี่ยนมากเมื่อข้อมูลบางส่วนผิดปกติ เช่น มัธยฐาน IQR MAD และ trimmed mean เปรียบเทียบความทนทานด้วย breakdown point อธิบายใน robust statistics: median, IQR, MAD, trimmed mean · ดูเพิ่ม Interquartile range (IQR), Mean / median
ROLLUP / CUBE (ROLLUP / CUBE)
ส่วนขยายของ GROUP BY ที่คำนวณหลายระดับการรวมในคำสั่งเดียว ROLLUP คำนวณตามลำดับชั้น CUBE คำนวณทุกชุดค่าผสม ใช้ GROUPING() แยกแถวผลรวมจากค่าว่างจริง อธิบายใน การดำเนินการแบบ OLAP: roll-up, drill-down, slice, dice · ดูเพิ่ม Aggregation, Drill-down
Scaling / standardization (การปรับสเกล / การทำให้เป็นมาตรฐาน)
การแปลงมิติของข้อมูลให้อยู่ในสเกลที่เทียบกันได้ การทำให้เป็นมาตรฐานทำให้แต่ละมิติมีค่าเฉลี่ย 0 และส่วนเบี่ยงเบนมาตรฐาน 1 ซึ่งกำหนดน้ำหนักของแต่ละมิติในวิธีที่อาศัยระยะทาง อธิบายใน ระยะทาง ความคล้าย และการปรับสเกล · ดูเพิ่ม Principal Component Analysis (PCA), Clustering
Schema (schema)
คำอธิบายโครงสร้างที่ข้อมูลต้องมี เช่น ชื่อคอลัมน์ ชนิดข้อมูล และกฎของค่า ทั้งในฐานข้อมูล (CREATE TABLE) และในการตรวจ DataFrame (pandera) อธิบายใน validation as code ด้วย pandera

Sensitivity analysis (การวิเคราะห์ความไว)
การคำนวณผลซ้ำด้วยทางเลือกที่สมเหตุสมผลต่างกัน เช่น เกณฑ์ความครบถ้วนหรือวิธีจัดการข้อมูลสูญหาย เพื่อดูว่าข้อสรุปเปลี่ยนหรือไม่ อธิบายใน คุณภาพข้อมูลและข้อมูลสูญหาย · ดูเพิ่ม Missing data, Garden of forking paths

Session state (session state)

Silhouette (silhouette)
ตัววัดว่าแต่ละจุดอยู่ใกล้กลุ่มของตนมากกว่ากลุ่มอื่นเพียงใด มีค่าระหว่าง −1 ถึง 1 ใช้ร่วมกับ elbow ความเสถียร และความหมายในการเลือกจำนวนกลุ่ม อธิบายใน การประเมิน cluster: silhouette และความเสถียร · ดูเพิ่ม Clustering
Simpson’s paradox (Simpson’s paradox)
ปรากฏการณ์ที่ความสัมพันธ์ในข้อมูลรวมตรงข้ามกับในทุกกลุ่มย่อย มักเกิดเมื่อองค์ประกอบของกลุ่มต่างกัน เช่น เครือข่ายสถานีขยายตัว อธิบายใน สหสัมพันธ์และกับดัก: Simpson’s paradox, ecological fallacy · ดูเพิ่ม Correlation, Ecological fallacy
Skewness (ความเบ้)
ตัววัดความไม่สมมาตรของการแจกแจง ค่าบวกหมายถึงหางยาวทางขวา ซึ่งทำให้ค่าเฉลี่ยสูงกว่ามัธยฐาน อธิบายใน การแจกแจงและรูปร่างของข้อมูล · ดูเพิ่ม Distribution

Spatial autocorrelation (สหสัมพันธ์เชิงพื้นที่)
ความสัมพันธ์ระหว่างค่าของตัวแปรเดียวกันในตำแหน่งที่ใกล้กัน วัดด้วย Moran’s I ทำให้หน่วยเชิงพื้นที่ไม่เป็นอิสระต่อกัน อธิบายใน spatial autocorrelation: Moran’s I · ดูเพิ่ม Autocorrelation
Spatial interpolation (การประมาณค่าเชิงพื้นที่)
การสร้างพื้นผิวต่อเนื่องจากค่าที่จุดตรวจวัด เช่น IDW และ kriging ไม่สามารถสร้างข้อมูลในบริเวณที่ไม่ได้วัด จึงต้องแสดงความไม่แน่นอนควบคู่ อธิบายใน การประมาณค่าเชิงพื้นที่จากเครือข่ายสถานี: IDW และ kriging เบื้องต้น · ดูเพิ่ม Spatial autocorrelation
Spatial join (spatial join)
การเชื่อมสองตารางด้วยความสัมพันธ์เชิงพื้นที่แทนคีย์ เช่น สถานีที่อยู่ภายในจังหวัด ต้องให้ทั้งสองชุดอยู่ใน CRS เดียวกัน อธิบายใน spatial operation และ spatial join · ดูเพิ่ม Join, Coordinate Reference System (CRS)

Stakeholder (ผู้มีส่วนได้ส่วนเสีย)
บุคคลหรือหน่วยงานที่ใช้ผลการวิเคราะห์หรือได้รับผลกระทบจากผลนั้น การคุยกับผู้มีส่วนได้ส่วนเสียช่วยให้คำถามนำไปใช้ได้ อธิบายใน แหล่งที่มาของสมมติฐาน: ความรู้โดเมน งานวิจัย ผู้ใช้ผลลัพธ์ และ first look

Synthetic data (ข้อมูลสังเคราะห์)

Table / view (ตาราง / view)

กฎที่กำหนดความต่างของเวลาท้องถิ่นจาก UTC เช่น Asia/Bangkok คือ UTC+07:00 ไม่มีเวลาออมแสง การตัดวันผิดเขตเวลาทำให้ค่าเฉลี่ยรายวันปนข้อมูลสองวัน อธิบายใน การจัดการวันเวลาและเขตเวลาใน SQL
Trace (Plotly) (trace)
ชุดข้อมูลหนึ่งชุดที่วาดด้วยเครื่องหมายหนึ่งแบบใน figure ของ Plotly figure ประกอบด้วยรายการ trace (data) และ layout อธิบายใน แบบจำลองของ Plotly: figure, trace, layout · ดูเพิ่ม Interactive
Treemap / sunburst (treemap / sunburst)
กราฟสำหรับข้อมูลลำดับชั้น treemap ใช้สี่เหลี่ยมซ้อนกัน sunburst ใช้วงแหวนซ้อนกัน ขนาดต้องเป็นค่าที่บวกกันได้ และสีใช้กับค่าที่ต้องการเปรียบเทียบ อธิบายใน treemap และ sunburst: อัลกอริทึมการจัดวาง · ดูเพิ่ม Hierarchy
Trend / seasonality (แนวโน้ม / ฤดูกาล)
องค์ประกอบของอนุกรมเวลา แนวโน้มคือการเปลี่ยนระดับระยะยาว ฤดูกาลคือรูปแบบที่ซ้ำในคาบแน่นอน PM2.5 มีฤดูกาลรายวัน รายสัปดาห์ และรายปี อธิบายใน องค์ประกอบของอนุกรมเวลา: trend, seasonality, residual · ดูเพิ่ม Decomposition
Upsert (upsert)
การเพิ่มแถวใหม่เมื่อ key ยังไม่มี และแก้ไขแถวเดิมเมื่อ key มีอยู่แล้ว ใน DuckDB ใช้ INSERT OR REPLACE หรือ INSERT … ON CONFLICT อธิบายใน การโหลดข้อมูลแบบ idempotent: upsert และการขจัดข้อมูลซ้ำ · ดูเพิ่ม Idempotent
Validation (การตรวจสอบความถูกต้อง)
การตรวจข้อมูลกับกฎที่กำหนดไว้ เช่น ชนิด ช่วงค่า และ key ที่ไม่ซ้ำ เขียนเป็นโค้ดด้วย pandera เพื่อให้ตรวจซ้ำได้ทุกครั้งที่ข้อมูลใหม่เข้ามา อธิบายใน validation as code ด้วย pandera · ดูเพิ่ม Schema
Version control (version control)
ระบบที่บันทึกการเปลี่ยนแปลงของไฟล์เป็นลำดับ พร้อมข้อมูลว่าใครเปลี่ยน เมื่อไร และทำไม ย้อนดูหรือย้อนกลับได้ และรวมงานของหลายคนได้อย่างเป็นระบบ เช่น Git อธิบายใน ทำไมต้องมี version control · ดูเพิ่ม Commit, Repository (repo)
Virtual environment (virtual environment)
โฟลเดอร์ที่มี site-packages แยกของโครงการหนึ่ง ทำให้แต่ละโครงการใช้แพ็กเกจคนละเวอร์ชันได้ การ activate คือการนำโฟลเดอร์ของสภาพแวดล้อมไปไว้หน้าสุดของ PATH อธิบายใน virtual environment ทำงานอย่างไร · ดูเพิ่ม Environment (Python)
Visualization (การนำเสนอข้อมูลด้วยภาพ)
การแปลงข้อมูลเป็นภาพเพื่อให้ผู้อ่านเห็นรูปแบบ ความผิดปกติ และความแตกต่าง โดยอาศัยระบบการมองเห็น ใช้ทั้งในการสำรวจและการสื่อสาร อธิบายใน การรับรู้ทางสายตา: preattentive attribute และหลัก Gestalt · ดูเพิ่ม Encoding (visual)
Web scraping (web scraping)
การดึงข้อมูลจากหน้าเว็บที่ออกแบบมาให้คนอ่าน ด้วยการแกะโครงสร้าง HTML เช่น ใช้ CSS selector กับ BeautifulSoup ใช้เมื่อไม่มี API และต้องเคารพ robots.txt ข้อกำหนดการใช้งาน และกฎหมาย อธิบายใน web scraping: DOM, CSS selector และ BeautifulSoup
Wide / long format (รูปแบบกว้าง / รูปแบบยาว)
รูปแบบกว้างกระจายค่าของตัวแปรเป็นหลายคอลัมน์ รูปแบบยาวรวมเป็นคอลัมน์ชื่อกับคอลัมน์ค่า แปลงไปมาด้วย melt และ pivot อธิบายใน reshaping: melt, pivot และ wide/long · ดูเพิ่ม Reshape
Window function (window function)
ฟังก์ชัน SQL ที่คำนวณค่าจากกลุ่มแถวที่สัมพันธ์กับแถวปัจจุบัน โดยไม่ยุบแถวเหมือน GROUP BY เช่น ค่าเฉลี่ยเคลื่อนที่ 7 วัน อันดับ หรือค่าของวันก่อนหน้า อธิบายใน window function: ranking, moving average, lag/lead · ดูเพิ่ม Aggregation, CTE
