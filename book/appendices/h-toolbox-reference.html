ตัวอย่างในหัวข้อนี้สมมติว่ามี DataFrame df ที่ได้จาก daily_pm25_clean join กับ stations (มีคอลัมน์ station_id, date, pm25_mean, pm25_max, is_complete, region, province) และ st คือตาราง stations

pandas และ Polars

ข้อควรจำ pandas ต้องเรียงข้อมูลตามเวลาก่อนใช้ rolling หรือ shift และใช้ resample กับข้อมูลที่มี index เป็นเวลา (resampling และความครบถ้วนของข้อมูลเมื่อรวมกลุ่ม) Polars แบบ lazy (df.lazy() หรือ pl.scan_parquet(...)) จะไม่คำนวณจนกว่าจะเรียก .collect() ซึ่งทำให้ Polars วางแผนการทำงานทั้งหมดได้ก่อน (Polars: expression และ lazy evaluation)

result = (
    pl.scan_parquet("data/processed/daily_pm25_clean.parquet")
    .filter(pl.col("is_complete"))
    .join(pl.scan_parquet("data/processed/stations.parquet"), on="station_id")
    .with_columns(month=pl.col("date").dt.month(), exceed=pl.col("pm25_mean") > 37.5)
    .group_by("region", "month")
    .agg(pl.col("pm25_mean").mean().alias("mean"), pl.col("exceed").sum().alias("n_exceed"))
    .sort("region", "month")
    .collect()
)

seaborn

ก่อนวาดทุกครั้งให้เรียก viz_style.setup() ของโครงการเพื่อตั้งฟอนต์ไทย (ตัวอักษรไทยในกราฟ) ฟังก์ชันระดับ figure เช่น relplot และ displot สร้าง figure ใหม่เอง จึงไม่รับอาร์กิวเมนต์ ax= ส่วนฟังก์ชันระดับ axes เช่น histplot และ boxplot วาดลง ax ที่ส่งเข้าไปได้

Plotly

กราฟโต้ตอบเก็บข้อมูลทุกจุดไว้ในไฟล์ HTML ข้อมูลรายวันของทุกสถานีหลายปีทำให้ไฟล์ใหญ่และเบราว์เซอร์ช้า ให้สรุปใน DuckDB ก่อน เช่น เป็นรายเดือน หรือใช้ Datashader กับข้อมูลระดับล้านจุด (visualization ข้อมูลขนาดใหญ่: binning, aggregation และ Datashader)

GeoPandas

ข้อผิดพลาดที่พบบ่อยที่สุดของข้อมูลเชิงพื้นที่คือการคำนวณระยะทางหรือพื้นที่ด้วยพิกัดองศา (EPSG:4326) ซึ่งได้หน่วยเป็นองศาและไม่มีความหมายทางกายภาพ ต้องแปลงเป็นระบบพิกัดแบบฉาย เช่น UTM ก่อน และ points_from_xy รับลองจิจูด (x) ก่อนละติจูด (y) เสมอ (ระบบพิกัดและเส้นโครงแผนที่สำหรับประเทศไทย (WGS 84, UTM 47N/48N))

Streamlit

โครงพื้นฐานของแอปที่อ่านจาก DuckDB มีลักษณะดังนี้ แอปเต็มของโครงการพร้อม drill-down อยู่ใน การออกแบบ drill-down หลายระดับ

from pathlib import Path

import duckdb
import pandas as pd
import plotly.express as px
import streamlit as st

DB = Path(__file__).resolve().parents[1] / "data" / "pm25.duckdb"


@st.cache_resource
def get_con():
    return duckdb.connect(str(DB), read_only=True)          # read-only: ไม่ล็อกไฟล์ที่ pipeline เขียน


@st.cache_data(ttl=3600)
def load_monthly(region: str) -> pd.DataFrame:
    sql = """SELECT date_trunc('month', d.date) AS month, avg(d.pm25_mean) AS pm25
             FROM daily_pm25_clean d JOIN stations s USING (station_id)
             WHERE s.region = ? AND d.is_complete GROUP BY ALL ORDER BY month"""
    return get_con().execute(sql, [region]).df()             # ใช้พารามิเตอร์ ? ไม่ต่อสตริง SQL


region = st.sidebar.selectbox("ภาค", ["เหนือ", "กลาง", "ตะวันออกเฉียงเหนือ", "ใต้"], key="region")
data = load_monthly(region)
c1, c2 = st.columns(2)
c1.metric("ค่าเฉลี่ยทั้งช่วง", f"{data['pm25'].mean():.1f} µg/m³")
c2.metric("เดือนที่เกินมาตรฐาน", int((data["pm25"] > 37.5).sum()))
st.plotly_chart(px.line(data, x="month", y="pm25"), width="stretch")
