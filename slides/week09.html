Grammar of graphics

กราฟ = ชั้นของไวยากรณ์

Wilkinson (1999) → ggplot2 (Wickham) → ไลบรารี Python หลายตัว

องค์ประกอบ ตัวอย่างจาก PM2.5
data (tidy) ข้อมูลรายวันที่ทำความสะอาดแล้ว: 1 แถว = 1 สถานีต่อ 1 วัน
encoding x = date, y = pm25_mean, color = region
mark จุด เส้น แท่ง กล่อง
scale แกน y แบบ log, palette สีของภาค
facet หนึ่งช่องต่อหนึ่งภาค
coordinate Cartesian, polar, พิกัดแผนที่ (สัปดาห์ที่ 13)

มี statistic ด้วย: การคำนวณก่อนวาด เช่น bin ของ histogram, มัธยฐานในกล่อง ประโยชน์: เปลี่ยนองค์ประกอบเดียวก็ได้กราฟใหม่ เช่น scatter → line แค่เปลี่ยน mark

seaborn.objects: เขียนตามไวยากรณ์ตรง ๆ

import seaborn.objects as so

(
    so.Plot(daily_region, x="date", y="pm25_median", color="region")  # data + encoding
    .add(so.Line())                                                    # mark
    .scale(y="log")                                                    # scale
    .facet(col="region", wrap=3)                                       # facet
)
  • มีตั้งแต่ seaborn 0.12
  • daily_region = มัธยฐาน PM2.5 รายวันต่อภาค

Altair (เสริม): ไวยากรณ์เดียวกันผ่าน Vega-Lite

import altair as alt

alt.Chart(daily_region).mark_line().encode(
    x="date:T", y="pm25_median:Q", color="region:N"
).facet(column="region:N")
  • ระบุชนิดข้อมูลหลังชื่อคอลัมน์
  • :Q quantitative · :N nominal · :O ordinal · :T temporal

เลือกกราฟจากชนิดของคำถาม

สี่กลุ่มคำถาม

ชนิดคำถาม กราฟที่เหมาะ หลีกเลี่ยง
distribution histplot, ecdfplot, kdeplot แท่งค่าเฉลี่ยอย่างเดียว
comparison boxplot, violinplot, stripplot pie chart หลายชิ้น
relationship scatterplot, regplot, histplot 2 มิติ scatter หลายแสนจุดแบบทึบ
time lineplot, heatmap เดือน × ปี แท่งเรียงวันละแท่ง

ตัวอย่างคำถาม: ค่ารายวันส่วนใหญ่อยู่ช่วงไหน / ภาคเหนือสูงกว่า กทม. ในฤดูแล้งไหม / ค่าเฉลี่ยสูงแล้วค่าสูงสุดรายชั่วโมงสูงตามไหม / มีรูปแบบรายเดือนหรือแนวโน้มรายปีไหม barplot ใช้เมื่อเทียบจำนวน/สัดส่วน

ฟังก์ชันสองระดับใน seaborn

ระดับ ฟังก์ชัน ใช้เมื่อ
figure displot, catplot, relplot ต้องการ facet ทันทีด้วย col= / row=
axes histplot, boxplot, lineplot วาดลง ax เดียว จัดหลายกราฟเอง

การรับรู้ภาพ

ตาคนอ่านอะไรได้แม่น

Cleveland & McGill (1984)

  • แม่นที่สุด (ซ้าย) → แม่นน้อยที่สุด (ขวา)
  • ค่าที่ต้องเทียบแม่น → วางบน ตำแหน่ง
  • pie ใช้ มุม → เทียบยากกว่า bar ที่ใช้ ความยาว
  • สี → แยกกลุ่ม หรือภาพรวมคร่าว ๆ (heatmap)

แกนที่ซื่อสัตย์ (honest axes)

กฎ เหตุผล
bar chart เริ่มที่ 0 ความยาวแท่งคือค่า
line / scatter ไม่จำเป็นต้องเริ่มที่ 0 อ่านจากตำแหน่ง แต่ติดป้ายแกนให้ชัด
กราฟที่เทียบกันใช้ scale เดียวกัน facet ใช้ sharey=True เป็นค่าเริ่มต้น
log scale ต้องเขียนกำกับ ผู้อ่านทั่วไปอาจอ่านผิด
ระบุหน่วยเสมอ “PM2.5 (µg/m³)” ไม่ใช่ “pm25_mean”

สีตามชนิดข้อมูล

ชนิดข้อมูล ตัวอย่าง PM2.5 ใน seaborn
categorical ภาค, ประเภทสถานี "colorblind", "tab10"
sequential ค่า PM2.5 ใน heatmap "viridis", "rocket", "mako"
diverging ส่วนต่างจากมาตรฐาน 37.5 "RdBu_r", "vlag"

Colorblind-safe

  • ผู้ชายประมาณ 8% บกพร่องการเห็นสีแดง-เขียว
  • อย่าใช้คู่แดง-เขียวเป็นตัวแยกกลุ่มหลัก
  • ใช้ sns.color_palette("colorblind") หรือตระกูล viridis (พิมพ์ขาวดำยังอ่านได้)
  • ไม่เกิน 6–8 สีต่อกราฟ มากกว่านั้นใช้ facet

Warning

“rainbow” / “jet” ไม่ควรใช้กับข้อมูลต่อเนื่อง: ความสว่างไม่ไล่ตามค่า เกิดขอบปลอมในภาพ

กราฟที่ชวนเข้าใจผิด

ปัญหาที่พบบ่อยและวิธีแก้

ปัญหา วิธีแก้
แท่งถูกตัดแกน เริ่มแกนที่ 0 หรือใช้ dot plot
แกนคู่ (dual axes) สองกราฟซ้อนแนวตั้งแกน x ร่วม หรือ scatter สองตัวแปร
overplotting alpha ต่ำ, จุดเล็ก, 2D histogram, สุ่ม, สรุปก่อนวาด
ค่าเฉลี่ยซ่อนการกระจาย box / violin / strip plot หรือ ECDF
เลือกช่วงเวลาให้เข้าข้าง แสดงทั้งหมดก่อน แล้วค่อยซูมพร้อมเหตุผล
ไม่บอกจำนวนตัวอย่าง ใส่ n ในป้ายหรือคำบรรยาย

ตัวอย่าง: แกน y เริ่มที่ 30 ทำให้เชียงใหม่ (45) ดูสูงกว่า กทม. (35) สามเท่า แกนคู่ PM2.5 กับ hotspot: เส้นทับกันพอดีเพราะผู้วาดเลือกช่วงแกนเอง overplotting: สัปดาห์ที่ 10 ใช้ Datashader

seaborn กับข้อมูล PM2.5

โหลดข้อมูล: แบ่งงานให้ถูกที่

  • DuckDB: join ข้อมูลรายวันที่ทำความสะอาดแล้วกับ stations และกรองข้อมูล
  • pandas / seaborn: รับเฉพาะตารางที่พร้อมวาด
  • ได้ DataFrame daily: สถานี วันที่ pm25_mean, pm25_max, n_hours, จังหวัด ภาค
  • แปลง date เป็น datetime และเพิ่มคอลัมน์ month

แนวทางนี้สำคัญมากในสัปดาห์ที่ 10 เมื่อข้อมูลใหญ่ขึ้น

Distribution: histogram + เส้นมาตรฐาน

THAI_STD, WHO_GUIDE = 37.5, 15

fig, ax = plt.subplots(figsize=(8, 4))
sns.histplot(data=daily, x="pm25_mean", bins=60, log_scale=True, ax=ax)
ax.axvline(THAI_STD, color="black", linestyle="--")
ax.axvline(WHO_GUIDE, color="gray", linestyle=":")
  • PM2.5 เบ้ขวา: ส่วนใหญ่ต่ำ แต่หางขวายาวมาก → ใช้ log scale
  • มาตรฐานไทย (ปี 2566) 37.5 µg/m³ · WHO (2021) 15 µg/m³
  • เส้นอ้างอิงช่วยให้ตีความ “สูง/ต่ำ” ได้โดยไม่ต้องเดา

Comparison: boxplot เรียงตามมัธยฐาน

order = daily.groupby("region")["pm25_mean"].median().sort_values().index
ax = sns.boxplot(data=daily, x="pm25_mean", y="region", order=order,
                 showfliers=False, color="lightsteelblue")
ax.axvline(THAI_STD, color="black", linestyle="--")
ax.set(xlabel="PM2.5 เฉลี่ย 24 ชม. (µg/m³)", ylabel="")
  • เรียงตามมัธยฐาน ไม่ใช่ตามตัวอักษร → อ่านลำดับได้ทันที
  • ชื่อภาคบนแกน y → ป้ายไทยไม่ซ้อนกัน

Time: รูปแบบตามฤดูกาล

ax = sns.lineplot(data=daily, x="month", y="pm25_mean", hue="region",
                  estimator="median", errorbar=("pi", 50))   # แถบ = ช่วงระหว่าง Q1–Q3
ax.axhline(THAI_STD, color="black", linestyle="--")
errorbar แถบบอกอะไร
("pi", 50) ความผันแปรของข้อมูลจริง (percentile 25–75)
("ci", 95) ความไม่แน่นอนของค่าประมาณ

ต้องเขียนกำกับให้ผู้อ่านรู้ว่าแถบหมายถึงอะไร

Relationship: 2D histogram แทน scatter

ax = sns.histplot(data=daily, x="pm25_mean", y="pm25_max", bins=80,
                  log_scale=True, cmap="mako")   # 2D histogram แทน scatter ที่ทับกัน
ax.set(xlabel="ค่าเฉลี่ย 24 ชม. (µg/m³)", ylabel="ค่าสูงสุดรายชั่วโมง (µg/m³)")

สรุป

  • เริ่มจากคำถาม กราฟทุกภาพบอกได้ว่าตอบข้อใด
  • กราฟ = data + encoding + mark + scale + facet + coordinate
  • ค่าที่ต้องเทียบแม่นใช้ตำแหน่ง · สีตรงชนิดข้อมูล · colorblind-safe
  • bar เริ่มที่ 0 · ไม่ใช้แกนคู่ · แก้ overplotting
  • ตั้ง font ไทยก่อนวาด + เส้นมาตรฐาน 37.5 µg/m³
